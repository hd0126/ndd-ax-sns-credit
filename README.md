# NDD · AX SNS 크레딧 실회의 자료

나노디스플레이연구실 의견수렴용 **가상 SNS / 배점 시연** 페이지입니다.

- 사이트(Pages): 아래 GitHub Pages URL
- 의견: 페이지 탭 **5. 의견 적기** → GitHub Issue 제출, 또는 [이슈 목록](https://github.com/hd0126/ndd-ax-sns-credit/issues?q=is%3Aissue+label%3Aopinion)
- 성격: 테스트·가상 데이터. 라이브 SNS 정산이 아닙니다.

## 실원 권한

private 저장소입니다. 사이트·이슈를 쓰려면 저장소 **읽기(또는 이슈 쓰기)** 권한이 필요합니다. 현돈에게 GitHub username을 알려 초대해 주세요.

## 로컬

`docs/index.html` 을 브라우저로 열어도 시연은 됩니다. 의견 Issue 제출만 GitHub 로그인이 필요합니다.
