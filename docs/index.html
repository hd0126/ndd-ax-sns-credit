AX가속화연구단이란

한국기계연구원(KIMM)이 2026.7.1. 운영체로 출범시킨 조직입니다.
연구·행정 전 부문의 AX(AI Transformation) 가속이 목적입니다.
특정 연구실만의 과제가 아니라, 기관 구성원이 쓸 수 있는 AI·데이터·협업 기반을 빠르게 깔자는 취지입니다.

근거: 출범·킥오프 메일(길형배), Kick-off 발표(백동천 단장 비전 세션), 혁신팀·내재화팀 자료. 우한창·김형우 메일은 현장 활동(VOC 등) 확인용으로 참고.

오늘 실회의와의 연결

내재화팀이 만든 KIMM-SNS 크레딧(점수) 초안·시뮬이 “우리 실에 맞는지” 의견을 모읍니다. 플랫폼이 라이브로 점수를 매기는 단계가 아니라, 가상 데이터로 배점이 타당한지 보는 단계입니다.

S-Credit은 교육·코칭과 별도로, 단순 설치는 0점이고 상대가 실제 업무에 쓰고 후기·댓글을 남기면 5점입니다. K-Credit 좋아요는 동일인 1일 3회만 점수에 들어갑니다.

새 글

S: 교육·코칭은 횟수×30. 단순 설치는 0점. 상대가 업무에 쓰고 후기·댓글을 남기면 +5. K 좋아요는 동일인 1일 3회만 점수.

내 크레딧 (실시간)

최종 (월상한 적용)0

순위

    배점표 바꾸며 보기

    숫자를 바꾸면 SNS 탭 점수·순위가 같이 바뀝니다.

    산식

    K = 글×p + 첫글×f + 댓글×c + ♥받음×r + ♥누름(1일 3회 상한)×g + 위키×w + 인용×i
    S = 교육×e + 실사용후기×s  ·  단순 설치 = 0
    최종 = min(K+S, 월상한)

    길형배 반영: 동일인 좋아요 1일 3회 반영 · 설치 0 · 실사용+후기/댓글 5 (구 타부서 50은 이 규칙으로 대체).
